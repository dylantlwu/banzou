# 伴奏歌词 · 上手测试清单

每次改完、打包之前，按这份清单把 app 当用户用一遍。单元测试只保证逻辑对，界面和操作要靠这一遍。

## 怎么测

浏览器测试模式：用真实的后端逻辑和真实音频，但所有保存都只写到 `.testlib`，不碰你的素材文件夹。

```bash
cd banzou
source ~/.cargo/env
npm run test:ui:setup      # 编译测试桥 + 建测试曲库（生成一首示例歌曲）
npm run test:ui            # 启动后打开 http://localhost:1420/?test
```

- 用自己的歌测：`node scripts/make-testlib.mjs --from ~/我的歌`（音频硬链接，不占空间，歌词复制一份）
- 想从「没有歌词」开始测：再加 `--empty`
- 测第一次打开（还没选素材文件夹）：`/?test&nolib`
- 测完重来：再跑一次 `npm run test:ui:setup`，测试曲库会恢复原样
- 窗口要测两个尺寸：常用的 1100×720，和最小的 800×520；浅色、深色各看一眼

浏览器测不到的（只能在打包好的 app 里试）：「导入 LRC」弹出的系统选择文件窗口、⌘A/⌘C/⌘V、AirPods 实际延迟。

## 清单

### 曲库
- [ ] 第一次打开（`/?test&nolib`）显示欢迎页，「选择文件夹…」后出现曲库；设置里显示并能换素材文件夹
- [ ] 歌都在，伴奏/人声/歌词/原曲/录音标签亮灭正确
- [ ] 窗口最小时侧栏按钮不被截断，长歌名显示省略号

### 演唱
- [ ] 选歌后歌词马上出现，当前句在中间
- [ ] 播放时歌词跟着走；点任意一句跳过去
- [ ] 触控板/滚轮或按住拖动能上下翻看歌词，到第一句/最后一句停住；拖动不会误跳
- [ ] 暂停时翻到哪停在哪；播放中停手 3 秒回到当前句；「回到当前句」按钮有效
- [ ] ↑/↓ 跳句、←/→ 快退快进、空格播放暂停、V 开关引导人声
- [ ] 歌词 −/+ 偏移生效，重开这首歌还在
- [ ] 有外部录音的歌能切到「外部录音」播放
- [ ] 底部播放控制始终在窗口里，不会被歌词顶出去

### 导入 LRC
- [ ] 没歌词的歌：导入后马上显示，侧栏「歌词」标签亮起
- [ ] 已有歌词的歌：先问是否替换；取消不改，替换后马上显示
- [ ] GBK 编码、逐字时间、带 [offset:] 的文件都能正确导入
- [ ] 空文件给出提示，不会清掉原歌词
- [ ] 打轴编辑器里粘贴带时间的 LRC，时间保留

### 智能对齐
- [ ] 导入 LRC 后自动按人声对齐（第一次几秒，之后走缓存），提示「对上 x/y 句」；「撤销对齐」回到导入原样
- [ ] 演唱页「智能对齐」按钮：对齐后存盘，可撤销；没有人声分轨的歌不显示
- [ ] 打轴页「智能对齐」：时间更新、可「撤销对齐」、保存后文件正确
- [ ] 粘贴纯文本点「自动打轴」：每句都有时间，播放时歌词跟得上
- [ ] 故意删掉一句再对齐：出现「可能漏了一句」，点插入后位置正确
- [ ] 「对照识别结果」默认收起，展开后「用这句」只改不同的那几个字
- [ ] 智能对齐需要真人演唱的人声分轨（示例歌曲是合成音，识别不出字），用 `--from` 带自己的歌测

### 打轴
- [ ] 粘贴歌词 → 开始打轴；空格开始并逐句打，Enter 插间奏
- [ ] 打到后面时列表跟着滚，顶部工具栏和左侧曲库始终可见

- [ ] ⌫ 撤销、↑/↓ 选行（选中行滚到可见）、⌥←/→ 微调

- [ ] 暂停、跳转、切歌后叠加层马上跟上；改字号 / 颜色 / 位置 / 显示下一句，叠加层实时变化

- [ ] 最小窗口时侧栏三个按钮不挤

### 一键开播 / 直播修音
- [ ] 测试：先退出正式 app（占着 17890 端口），运行 devlive，再用 `/?test&fakemic`
- [ ] OBS 没开时点「● 开始直播」：几秒内 OBS 自动打开（不弹首次说明 / 安全模式），建好「伴奏歌词」场景和浏览器源，面板显示「OBS 已准备好」
- [ ] 播放时面板显示「我 X → 目标 Y · 修正 N 音分」；OBS 混音器里「伴奏歌词（歌词 + 声音）」有电平且不超过 0dB
- [ ] 填了推流地址和推流码：开始推流、显示直播时长；「结束直播」停止推流
- [ ] 没有麦克风：提示「只推伴奏和歌词」，照样能开
- [ ] 直播中改修音强度 / 自然↔电音 / 效果 / 音量，马上生效；换歌自动换原唱参考

### 录唱（M2）
- [ ] 测试模式用 `/?test&fakemic`：假麦克风 = 原唱人声晚 90ms 跟着唱
- [ ] 「● 录音」打开准备栏：麦克风列表里 AirPods 灰掉不能选；电平表有反应；输出设备显示正确（外放时红色提醒）
- [ ] 输入一直满格 / 没声音时有提示（扩展坞空接口、静音）
- [ ] 整首 / 从当前位置：先录 2 秒底噪 → 3-2-1 → 伴奏开始；空格停止；播到结尾自动停
- [ ] 存成「第 N 遍」，按原唱自动对齐（假麦克风应挪 -80~-100ms），离线互相关峰值在 0
- [ ] 选中一遍：回放「伴奏 + 我的声音」；V 切到原唱对比；「我的声音」音量、对齐微调生效并保存
- [ ] A / B（或 [ ]）设区间，进度条显示循环段；补录 A-B：录到 B 后自动停，生成「… · 补录 a–b」，原来那遍还在
- [ ] 录音时不循环、不能切歌、不能拖进度条；录完 A-B 循环恢复
- [ ] 删除：再点一次确认；只把没人用的录音文件移到废纸篓
- [ ] 改名（双击）、标星
- [ ] 录到一半强制退出 → 下次打开这首歌，录音被恢复到列表
- [ ] 正式 app：第一次录音系统弹麦克风授权；「校准延迟」跟着节拍说「嗒」能测出延迟

### 修音（M3）
- [ ] 录音列表选中一遍 →「去修音」：拼接录音、分析音高（一首歌一两秒，之后有缓存）
- [ ] 钢琴卷帘：灰 = 原唱、蓝 = 我的、红 = 跑调（颤音不算）、绿 = 修后；滚轮上下、横向翻页、⌘ + 滚轮缩放、点击跳转；播放时跟着走
- [ ] 歌词条：点句子选中，只修选中的句（其余压暗）
- [ ] 参考 原唱 / 音阶、调（自动检测，升降调录的会跟着移）、强度、自然 ↔ 电音：曲线和「音准 a% → b%」实时变
- [ ] 应用修音：几秒内生成，自动切到「修后」；改参数后提示过期；修前 / 修后切换、V 听原唱
- [ ] 降噪：有录前底噪时用底噪做参考
- [ ] 效果：干净 / 流行 / 温暖、均衡 / 压缩 / 混响开关、人声 / 伴奏音量，试听实时生效
- [ ] 导出：成品 wav + m4a、修后干声 wav，存到「录音/<歌名>/导出」，可在访达中显示；成品时长 = 伴奏时长，不爆音
- [ ] 删除一遍时，拼接和修音生成的中间文件一起移到废纸篓
- [ ] 升降调 ±6：第一次处理一两秒，之后秒开；引导人声一起移；在升调下录的那遍修音时原唱参考跟着移
- [ ] 搜索框（⌘F）：按歌名 / 原唱过滤，回车选第一首，Esc 清空
- [ ] 全屏大字（F / 按钮）：隐藏曲库和编辑按钮，Esc 退出

### 手动修音（M4）
- [ ] 修音页切到「音符」：自动切好的音符块（蓝）、改过的（橙，带 +N 标记）、和原唱差 > 30 音分的红框
- [ ] 点选 / ⇧ 多选；上下拖动改音高，默认吸附原唱 / 半音，⌥ 自由；双击吸附原唱；右键还原
- [ ] ↑↓ 半音、⇧↑↓ 10 音分；S 切分工具、⌘J 合并；⌘Z / ⇧⌘Z；全部还原
- [ ] 选中音符的拉直 / 颤音 / 过渡滑杆，松手后生效
- [ ] 改完自动只重渲那一段（几百毫秒），修后音频里那个音真的变了，其他地方不变
- [ ] 第一次改动（还没应用过修音）会先整首渲染；自动修音参数改过后再改音符会整首重渲
- [ ] 音符编辑存进 tune.json，关掉再开还在；改过的音符之后调自动修音参数不会被覆盖

### 练声（M6）
- [ ] 测试模式用 `/?test&fakemic`：假麦克风按目标音偏高 15 音分唱、气息时发噪声
