# 伴奏歌词 Banzou

给唱歌的人用的 macOS 应用：放伴奏、歌词跟着滚、录唱、修音、每天练声、一键开直播。

> **English**: Banzou is a macOS app for singers. It plays backing tracks with synced lyrics, records takes aligned to the original vocal, and offers auto and manual pitch correction. It also has daily vocal exercises and one-click live streaming through OBS with real-time pitch correction. The UI is in Chinese. Bring your own backing tracks and lyrics, since none are included. Download the latest build (Apple silicon) from [Releases](https://github.com/dylantlwu/banzou/releases/latest). It is not notarized, so on first launch allow it under System Settings → Privacy & Security → Open Anyway.

**目录**：[安装](#安装) · [5 分钟上手](#5-分钟上手) · [准备素材](#准备素材) · [唱歌](#唱歌) · [歌词](#歌词) · [耳机延迟](#耳机延迟校准) · [录唱](#录唱) · [修音](#修音) · [练声](#练声) · [直播](#直播) · [快捷键](#快捷键) · [常见问题](#常见问题) · [开发](#开发)

## 安装

### 下载（推荐）

只支持 Apple 芯片的 Mac（M1 或更新）。在 macOS 26 上测试过，更早的系统没测过。

1. 打开 [Releases 页面](https://github.com/dylantlwu/banzou/releases/latest)，下载 `Banzou-版本号-macOS-arm64.zip`
2. 双击解压，得到「伴奏歌词」，把它拖进「应用程序」文件夹
3. **第一次打开要多做一步**。这个应用没有经过 Apple 公证（需要付费开发者账号），所以第一次双击会提示「未打开“伴奏歌词”，Apple 无法验证…」：
   - 点「完成」，**不要点「移到废纸篓」**
   - 打开「系统设置 → 隐私与安全性」，拉到最下面，看到「已阻止“伴奏歌词”…」，点「仍要打开」，输入开机密码确认
   - 再双击打开就行，以后不会再问
4. 第一次录音、练声或直播时会问能不能用麦克风，点「允许」

如果第 3 步在「隐私与安全性」里找不到「仍要打开」，也可以在「终端」里运行下面这行，然后再双击打开：

```bash
xattr -dr com.apple.quarantine /Applications/伴奏歌词.app
```

想直播的话还要装 [OBS Studio](https://obsproject.com/)（30 或更新版本），装好就行，不用设置。

### 自己编译

想改代码，或者不想用下载版，可以自己编译一次（大约 5 分钟）。

**需要**

- Mac（Apple 芯片），推荐 macOS 26 或更新版本。「智能对齐」用到 macOS 26 的语音识别；更早的系统没测过
- Xcode：从 App Store 安装，装完打开一次，同意许可
- Rust：在终端运行 `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
- Node.js 20 或更新版本：从 [nodejs.org](https://nodejs.org/) 下载安装

**编译**

在「终端」里依次运行：

```bash
git clone https://github.com/dylantlwu/banzou.git
cd banzou
npm install
npm run tauri build
```

完成后应用在 `src-tauri/target/release/bundle/macos/伴奏歌词.app`。把它拖进「应用程序」文件夹，就和普通应用一样打开（自己编译的不需要第 3 步）。

## 5 分钟上手

1. **准备一个文件夹**：把伴奏放进去，命名成 `歌名 - 伴奏.mp3`。有分离出来的原唱人声，就命名成 `歌名 - 人声.wav` 一起放进去。有歌词文件的话命名成 `歌名.lrc`。详见[准备素材](#准备素材)
2. **打开应用**，点「选择文件夹…」，选刚才的文件夹。左边出现歌曲列表
3. **点一首歌**，按空格播放。歌词跟着滚，当前句在中间高亮
4. **没有歌词？** 点右上角「编辑歌词」，粘贴歌词文本，点「自动打轴」。需要有人声文件，详见[歌词](#歌词)
5. **戴 AirPods 等蓝牙耳机？** 打开「设置 → 跟拍校准」测一下耳机延迟，歌词就不会比声音快
6. 想录下来就点「● 录音」，想练基本功就点左上「练声」，想直播就点「直播」

## 准备素材

本应用不带任何歌曲。请用你有权使用的伴奏和歌词。

第一次打开时选的文件夹叫「素材文件夹」，应用只看它**第一层**的文件，子文件夹不看。之后可以在「设置 → 素材文件夹 → 换一个…」里更换。

| 文件名 | 是什么 | 必须吗 |
|---|---|---|
| `歌名 - 伴奏.wav`（或 `.mp3` / `.m4a` / `.flac`） | 伴奏 | 必须 |
| `歌名 - 人声.wav` | 原唱人声（分离出来的干声） | 可选，有了才能用：引导人声、自动打轴、智能对齐、按原唱修音、录音自动对齐 |
| `歌名.lrc` | 带时间的歌词 | 可选，也可以在应用里导入或打轴 |
| 任意视频，文件名里有歌名 | 原曲视频，可以打开或抽出音频对比 | 可选 |
| 其他音频，文件名里有歌名 | 外部录音（例如用手机录的） | 可选 |

小提示：

- 「歌名」两边的文字要完全一样，中间是「空格 - 空格」
- 同一首歌放了 wav 和 mp3 两份伴奏时，优先用 wav
- 文件名里写「（原唱：xx）」会被识别成原唱歌手
- 伴奏和人声可以用人声分离工具从你买的歌里分出来，例如 [Ultimate Vocal Remover](https://github.com/Anjok07/ultimatevocalremovergui)
- 放了新文件后点左上「重新扫描」

## 唱歌

点左边的歌就进入演唱页。

- **播放**：空格播放 / 暂停，← / → 快退 / 快进 5 秒，点进度条跳转
- **歌词**：播放时自动滚动。点任意一句跳过去，↑ / ↓ 跳到上一句 / 下一句。用触控板或滚轮可以往前往后翻看，停手 3 秒后自动回到当前句
- **引导人声**：底部「引导人声」开关（或按 V），旁边的滑杆调原唱音量。不熟的歌先带着原唱唱
- **歌词偏移**：右上「歌词 − 0 +」。歌词整体早了或晚了就调这里，每首歌单独记住
- **循环练一段**：唱到想练的段落开头按 `[`，结尾按 `]`，就会在这段里反复播放。按 `\` 取消。也可以点进度条右边的 A / B
- **升降调**：底部「升降调 − 0 +」，±6 个半音。第一次处理要一两秒，引导人声会一起变
- **变速**：底部「速度」，0.5–1.5 倍，音调不变，适合慢速练难段
- **全屏大字**：按 F 或点「全屏」，只剩大字歌词。Esc 退出
- **搜索**：⌘F，输入歌名或原唱，回车选第一首
- **原曲 / 外部录音**：有原曲视频的歌，标题下面有「打开 / 在访达中显示 / 抽出音频」。抽出后，底部可以在「伴奏 / 原曲」之间切换

## 歌词

有三种方式，都在演唱页右上：

**1. 导入 LRC**：点「导入 LRC」，选一个 `.lrc` 文件。GBK、UTF-16 编码都能读。有人声文件的话会自动对齐一次，提示「对上 x/y 句」，不满意可以点「撤销对齐」。

**2. 自动打轴**（需要人声文件）：点「编辑歌词」，把歌词文本粘贴进去，一行一句，然后点「自动打轴」。应用会用 Mac 自带的语音识别听原唱人声，给每句定好时间，不联网，第一次要几秒。

- 有漏掉的句子会提示「可能漏了一句」，点「插入」
- 识别出来的字和歌词不一样时，展开「对照识别结果」，点「用这句」改错字

**3. 手动打轴**：点「编辑歌词」，粘贴歌词，点「开始打轴」。

- 按空格开始播放，之后每句歌词**开始唱的那一刻**按一下空格
- Enter：插入间奏（空行）
- ⌫：撤销上一下，并倒回 3 秒重来
- ↑ / ↓：选中某一句，⌥← / ⌥→ 每次挪 50 毫秒
- 也可以在波形上直接拖动时间点
- 打完点「预览」听一遍，⌘S 保存

已经有歌词的歌，点演唱页的「智能对齐」可以按人声重新对一遍时间。

## 耳机延迟校准

蓝牙耳机（AirPods 等）的声音会晚 0.15–0.25 秒到耳朵，歌词会显得比声音快，打轴也会偏晚。

打开「设置」，点「跟拍校准」，跟着耳机里的节拍按空格，就能测出延迟，应用会自动扣掉。有线耳机或外放填 0。换耳机后重新校准。

「打轴反应时间」是按空格通常比真正开唱晚的那一点时间。打出来的歌词整体偏晚就调大，偏早就调小。

## 录唱

1. 选一首有伴奏的歌，点底部「● 录音」（或按 R），出现录音准备栏
2. **选麦克风**：蓝牙麦克风会被灰掉。AirPods 的麦克风一打开，耳机就会切到通话音质，所以只能用 Mac 内置麦克风、USB 麦克风或声卡。用 AirPods 听伴奏没问题
3. 第一次用某个耳机，先点「校准延迟」：跟着节拍对着麦克风说「嗒」
4. 选「整首」或「从当前位置」，点「● 开始录音（R）」。先安静 2 秒（应用要录一段环境噪音，降噪时用），倒数 3-2-1 后伴奏开始
5. 按空格停止，播到结尾也会自动停

录完会存成「第 1 遍」「第 2 遍」…，出现在右边列表里。有人声文件的话，会按原唱自动对齐时间。

- **回放**：选中一遍，播放的是「伴奏 + 我的声音」。按 V 切到原唱对比
- **对齐微调**：觉得声音和伴奏没对齐，边播边拖「对齐微调」
- **补录**：用 `[` `]` 框出唱得不好的一段，点「补录 A-B」，只重录这一段，原来那遍还在
- **管理**：双击改名、标星、删除（移到废纸篓，不会彻底删掉）
- **拼接**：录了两遍以上时点「拼接」，每句挑唱得最好的那遍，合成「拼接版」
- **去修音**：选中一遍，点「去修音」

录音文件存在素材文件夹的 `录音/歌名/` 里。录到一半应用崩溃或强制退出也不会丢，下次打开会恢复。

## 修音

在录音列表里选一遍，点「去修音」。

**自动修音（「曲线」视图）**

- 灰线 = 原唱，蓝线 = 你唱的，红色 = 跑调超过 30 音分（颤音不算），绿线 = 修后
- **参考**：「原唱」是往原唱旋律上修（需要人声文件）；「音阶」是吸到调里最近的音
- **调**：自动检测，可以改
- **强度**：修多少。**自然 ↔ 电音**：越往电音，转音越硬
- 只想修某几句：点上面的歌词条选中那几句
- 改完参数点「应用修音」，几秒后自动切到「修后」。用「修前 / 修后」对比，V 听原唱
- 上方「音准 a% → b%」是修前修后在调上的比例

**手动修音（「音符」视图）**：自动修不好的音在这里一个个改。

- 点选音符，⇧ 多选。上下拖动改音高，默认吸附原唱或半音，按住 ⌥ 自由拖动
- 双击：吸附到原唱。右键：还原这个音
- ↑ / ↓ 一个半音，⇧↑ / ⇧↓ 10 音分
- 「✂ 切分」（S）把一个音切成两个，⌘J 合并
- 选中音符后可以调「拉直 / 颤音 / 过渡」
- ⌘Z 撤销，⇧⌘Z 重做，「全部还原」从头来
- 改完自动只重新渲染那一小段，马上能听

**声音处理**

- **降噪**：去掉底噪，用录音前那 2 秒环境声做参考
- **效果**：干净 / 流行 / 温暖，或分别开关均衡、压缩、混响
- **音量**：人声和伴奏音量

**导出**：点「导出」，可以选：

- 成品（伴奏 + 人声，带效果）wav + m4a：m4a 体积小，手机、剪映、TikTok 都能用
- 修后干声 wav：拿去别的软件继续做

导出的文件存在 `录音/歌名/导出/`，点「在访达中显示」能找到。

## 练声

点左上「练声」，像专业歌手一样每天练基本功。**戴耳机练**，不然麦克风会把钢琴声也收进去。

1. **先做一次「音域测试」**：唱一个舒服的最低音，稳住 1.5 秒；再唱最高音。之后所有练习都按你的音域安排
2. 点「▶ 今日练习」，大约 12 分钟按顺序练完：哼鸣 → 气息 → 长音 → 五度音阶 → 琶音 → 听音模唱。也可以在左边单独选一项

| 项目 | 怎么练 | 看什么 |
|---|---|---|
| 哼鸣热身 | 闭嘴哼「嗯」，跟钢琴唱 1-2-3-4-5-4-3-2-1，每轮升半音 | 每个音准不准 |
| 气息 | 吸满气，发长长的「嘶——」 | 能坚持几秒、稳不稳。先练到 20 秒，再到 30 秒 |
| 长音 | 听到一个音后稳住唱 8 秒 | 平均偏差、抖动（20 音分以内很好） |
| 五度音阶 / 琶音 / 八度跳 | 用「啊」「哦」跟钢琴唱 | 准确率 |
| 听音模唱 | 听钢琴弹一个音，唱出同一个音，10 题 | 准确率 |

- 画面上，灰条是要唱的音，蓝线是你唱的。打完分的音变色：绿 = 准（25 音分以内），黄 = 差一点，红 = 跑调，灰 = 没唱
- 下面会实时显示「偏高 / 偏低 多少音分」
- 唱高八度或低八度都算对，男声女声都能用
- 底部记录最近 30 天的练习日历、准确率、气息和长音的趋势，还有连续练习天数

## 直播

把唱歌直播到 TikTok 等平台：观众看到滚动的歌词，听到伴奏和**修过音**的歌声，你耳机里听的是自己的原声。

**准备**

- 装好 [OBS Studio](https://obsproject.com/)
- 一个麦克风（USB 麦克风或声卡）。别用 AirPods 麦克风，蓝牙会切到通话音质
- 有线耳机，插在麦克风或声卡的耳机孔上听自己
- TikTok 推流码：在 TikTok 的直播设置里找（电脑推流 / LIVE Producer），需要账号有电脑直播权限

**开播**

1. 点左上「直播」，打开直播面板
2. 第一次：展开「推流设置（TikTok）」，填「推流地址（Server URL）」和「推流码（Stream Key）」。只存在你这台电脑上
3. 选麦克风，按需要调「直播修音」：强度、自然 ↔ 电音、效果、人声 / 伴奏音量
4. 点「● 开始直播」。应用会自动打开 OBS，建好「伴奏歌词」场景（歌词 + 声音），然后开始推流。面板显示直播时长
5. 选歌播放，开唱。面板会实时显示「我 X → 目标 Y · 修正 N 音分」
6. 唱完点「结束直播」

不填推流码也能点「● 开始直播」：会准备好 OBS 场景，但不推流，可以先自己看效果。直播中可以照常录音，录下的是没修过的原声。

**只要歌词叠加层**：自己在 OBS 里设置的话，打开「歌词同步到叠加层」，在 OBS 里加一个「浏览器」源，地址填面板里显示的 `http://127.0.0.1:17890/overlay`。也可以用「歌词窗口 · 绿幕 / 黑底」做窗口采集。字号、颜色、位置、是否显示下一句都能调。

注意：直播平台可能会静音或下架用了商业歌曲伴奏的直播。

## 常见问题

**打开时提示「Apple 无法验证」或「已损坏」。** 下载版没有经过 Apple 公证，第一次要手动放行，见[安装](#下载推荐)第 3 步。

**打开后左边是空的。** 检查文件名是不是「歌名 - 伴奏.mp3」这样，中间是「空格 - 空格」；文件要放在文件夹第一层。改好后点「重新扫描」。

**歌词比声音快 / 慢。** 戴蓝牙耳机先做「设置 → 跟拍校准」。只是某首歌不准，就用演唱页右上的「歌词 − +」调。

**「自动打轴」「智能对齐」「引导人声」按钮没有出现。** 这些都需要 `歌名 - 人声.wav` 原唱人声文件。

**录音时 AirPods 的音质突然变差。** 那是 AirPods 的麦克风被打开了。录音栏里选 Mac 内置麦克风或别的麦克风，应用默认就不会选蓝牙麦克风。

**第一次录音没反应。** macOS 会弹出麦克风权限请求，点「允许」。点过「不允许」的话，到「系统设置 → 隐私与安全性 → 麦克风」里打开「伴奏歌词」。

**点「开始直播」后 OBS 没反应。** 确认 OBS 装在「应用程序」里，版本 30 或更新。第一次用时如果 OBS 已经开着，应用连不上它，会提示「请退出 OBS 再点一次」：退出 OBS 后再点「● 开始直播」，应用会用自己的连接设置重新打开 OBS。

## 开发

```bash
npm run tauri dev      # 开发模式启动应用
npm test               # 前端单元测试（Vitest）
npm run test:rust      # 后端测试（cargo test）
```

**浏览器测试模式**：在浏览器里跑界面，命令交给真实的 Rust 后端逻辑执行，所有保存只写到 `.testlib`，不碰你的素材文件夹。

```bash
npm run test:ui:setup  # 编译测试桥，生成一首示例歌曲（合成的伴奏和人声，原创歌词）
npm run test:ui        # 然后打开 http://localhost:1420/?test
```

- `/?test&fakemic`：假麦克风，会跟着原唱人声唱（测录音、对齐、练声）
- `/?test&nolib`：模拟第一次打开
- 用自己的歌测：`node scripts/make-testlib.mjs --from ~/我的歌`
- 测直播叠加层要另外运行 `src-tauri/target/release/examples/devlive`

改完东西、打包前，按 [docs/测试清单.md](docs/测试清单.md) 把应用实际用一遍。需求和设计见 [docs/PRD.md](docs/PRD.md)。

**目录**

- `src/`：React 界面。`audio/` 播放引擎，`lyrics/` 歌词与对齐，`takes/` 录音，`tune/` 修音，`practice/` 练声，`live/` 直播
- `src-tauri/src/`：Rust 后端。`library.rs` 曲库配对，`dsp/` 音高检测 / PSOLA / 降噪 / 变调，`live.rs` 叠加层服务，`obs.rs` 控制 OBS
- `src-tauri/helpers/helper.swift`：语音识别、音频设备检测（编译时由 `build.rs` 用 `swiftc` 编译）
- `src-tauri/overlay/`：直播叠加层页面
